Settings and the Control Panel
==============================

bdos keeps its settings in C:\BDOS\SETTINGS.INI, one key=value per line.
Three ways to change them, all the same underneath:

  On the desktop   Control Panel (in Program Manager's Main group, or
                   Options > Control Panel, or type CONTROL in a shell)
  At the prompt    CONTROL                      lists every setting
                   CONTROL mouse.speed=7        changes one
  From programs    SYS "OS_SetSetting", "mouse.speed", 7        (BASIC)
                   os_set_setting("mouse.speed", 7);           (C)
                   SYS "OS_Setting", "clock.24h" TO s$         reads one

Changes take effect straight away and are saved.

The applets
-----------
Date/Time   the clock, the calendar, 24-hour or am/pm
Network     this computer's name; browse the LAN and open a shell or a
            desktop on another machine (T: is your folder there)
Desktop     background colour; follow the time of day (Play a Day shows
            it off); whether WIN starts at boot (it edits the WIN line in
            AUTOEXEC.BAT for you)
Themes      window colours, desktop colour and pattern together - try
            Hot Dog Stand. Themes are .THM files in C:\BDOS\THEMES, plain
            key=value text; Save As makes one from what's on screen
Mouse       pointer speed, double-click speed, swap buttons
Keyboard    key repeat delay and rate
System      version, processor, memory, display, network, drives

CONTROL DATE, CONTROL MOUSE and so on open one applet directly.

The clock from the prompt
-------------------------
DATE                 shows the date and asks for a new one (Enter keeps it)
DATE 2026-10-20      sets it (10-20-2026 works too)
TIME 19:05           sets the time (TIME 7:05 pm works too)
DATE /T, TIME /T     just show

Windows
-------
Drag any edge or corner of a window to resize it; shells reflow to the
new size. Double-click a title bar, or press the button beside the close
box, to maximize; do it again to restore. The down arrow minimizes it to
an icon at the bottom of the screen; double-click the icon to bring it
back. Right-click a title bar (or press Alt+Space) for the control menu.
Right-click the desktop for New Shell, File Manager, Themes, Tile...

Program Manager and File Manager
--------------------------------
Program Manager's groups are the folders in C:\PROGMAN, and its icons are
the files in them. A .LNK file's first line is the command it runs; any
other file opens the way File Manager would open it. So you can manage
groups from File Manager or the prompt too: MD C:\PROGMAN\TOOLS makes a
group.

File Manager keys: Enter opens, Backspace goes up, Del deletes, F2
renames, F5 refreshes, F7 moves, F8 copies, Ctrl+N makes a folder, Ctrl+A
selects everything, Tab switches between the tree and the list. Drag files
to move them (Ctrl copies; dragging to another drive always copies).

The network
-----------
IPCONFIG             this machine's address (DHCP unless you set one)
IPCONFIG /RENEW      ask the DHCP server again
PING 10.0.2.2        does that machine answer?
CONTROL net.ip=192.168.1.50   a fixed address (and net.mask, net.gateway)
CONTROL net.ip=dhcp           back to DHCP
CONTROL net.password=secret   bterm must give this password
CONTROL net.udp=0             no bterm or routed BDNET at all

bterm (on Linux or a Mac) shows this machine's desktop in a window, or a
shell with -t. The folder it was started from is T: here.
